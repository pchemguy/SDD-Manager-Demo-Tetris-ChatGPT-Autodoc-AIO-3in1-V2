# Milestone 4.1 - Session-only settings

## Outcome

Version 0.4.0 exposes six canonical settings in a hideable shared panel. Defaults enable hold/drop/preview and show the ghost, with full-interval general locking. User changes apply immediately without restart. This increment deliberately keeps configuration only in page memory.
