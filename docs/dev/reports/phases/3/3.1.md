## Code review

Reviewed the single deepest-landing owner, occupancy-preserving transit and validation callback used by SRS; legal transformations always retain a non-overlapping visible final candidate. Only completed final cells merge. Activation that cannot admit any final landing leaves bonuses untouched. Grounding clears only on actual descent availability and retains the original deadline when activation does not lift the piece. New pieces are regular and hold eligibility resets after lock. White settled cells identify penetrator placement; regular piece generation and previews never use white.

Reviewed renderer mode/color/predicate separation, bonus subscription updates and real pixel expectations. Normal and penetrator projections use the same drop destination as the core; dynamic visibility tests occupied rows, not a bounding-box origin. Packaging now independently guards against accidentally shipping the view test harness. No confirmed blocker remains.

Settings, score history/files and additional platforms are not claimed by this phase.
